# Front

Ver el `README.md` de la carpeta raíz del proyecto (instalación, variables de entorno y contrato de la API).


## Estructura del frontend

El código de la aplicación React se encuentra en `frontend/src`, organizado por módulos de dominio (`features`) y carpetas transversales (`api`, `components`, `config`, `hooks` y `routes`). Se conserva JavaScript/JSX porque el proyecto original no está configurado con TypeScript.
